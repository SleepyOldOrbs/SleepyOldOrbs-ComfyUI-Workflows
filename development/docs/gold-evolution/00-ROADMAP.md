# Gold Standard Workflow Evolution

This folder records six staged, recoverable upgrades to:

`07 GOLD STANDARD - Complete Krea2 Pipeline.json`

Each stage has four deliverables:

1. A **before-stage backup** beside the live workflow.
2. An **openable teaching checkpoint** in `Codex MCP Demos/Gold Evolution`.
3. **Embedded Pixaroma notes** inside the workflow.
4. A **stage document** here covering purpose, operation, validation, and recovery.

## Planned stages

| Stage | Capability | Intended result |
|---|---|---|
| 1 | Reference-image controls | Optional H3 Ref2VA pass with identity and world/wardrobe/prop references |
| 2 | Selective repair | Paint a region, regenerate only its crop, and stitch it back without touching the rest |
| 3 | H3 continuation | Take the last frame of the first H3 clip and continue into a second clip |
| 4 | Storyboard mode | Use several visual keyframes as a controlled reference sequence |
| 5 | VRAM choreography | Release prompt, diffusion, and upscale models at deliberate hand-off points |
| 6 | Character and project presets | Save and reapply coherent control-desk configurations |

The live gold workflow always advances to the latest validated stage. Earlier teaching checkpoints remain unchanged so they can be opened for comparison.
